# SPLA RUSH!! (スプラ・ラッシュ)

イカ vs タコの 3 分間ペイントバトル。ブラウザで動く三人称視点の 3D アクションシューティングです。
カラフルな塗料でステージの床を塗り合い、試合終了時に塗った面積が広いチームが勝ちます。

![genre](https://img.shields.io/badge/genre-3D%20turf%20shooter-orange)

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開き、「バトルスタート」をクリック。

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D |
| カメラ / 照準 | マウス |
| インク発射 | 左クリック（地面も塗れる） |
| ジャンプ | Space |
| イカスイム | Shift（自分のインクの上のみ。高速移動 + インク回復） |
| ポーズ | Esc |

## ルール

- 1 試合 3 分。プレイヤー + 味方 AI 2 体（イカチーム） vs 敵 AI 3 体（タコぐんだん）。
- 自分の色の上では速く、敵の色の上では大きく減速する。
- 射撃はインクエネルギーを消費。自分のインクでスイムすると急速回復する。
- 敵を倒すと数秒間リスポーンさせ、大きなスプラットを残す。
- 敵 AI の狙いはゆっくり漂うブレを持ち、バースト射撃の合間に必ず休みを入れる。
  静止した相手に 8m でおよそ 5 割、動く相手にはさらに落ちる。

## 技術構成

- TypeScript + Vite + Three.js（依存はこの 3 つのみ）
- ペイント: Canvas 2D のスプラットアトラス（2048²）+ 0.25m 格子の CPU 集計グリッド
- 物理: 自前の AABB キャラクタコントローラ（ステップアップ / 段差 / 天井判定）
- AI: ユーティリティベースの行動選択（塗り拡げ / 交戦 / 撤退 / 自陣防衛 / 高所確保）+ A* 経路探索
- 描画: PBR + PMREM 環境光 + ソフトシャドウ + GTAO + Bloom + SMAA + ビネット/色収差
- サウンド: Web Audio 全合成（効果音 + BGM シーケンサ、外部音源なし）

## デバッグ用 URL パラメータ

| パラメータ | 効果 |
| --- | --- |
| `?auto=1` | プレイヤーも AI が操作（自動観戦） |
| `?speed=N` | 時間スケール |
| `?t=N` | 試合時間（秒） |
| `?quick=1` | タイトルをスキップして即開始 |
| `?nogtao=1` / `?nobloom=1` / `?nosmaa=1` | 各ポストエフェクトを無効化 |

## 実装上の注意点（触るときに踏みやすい罠）

- ANGLE/D3D11 環境では「MSAA レンダーターゲット」や「フレーム途中のシザー付き RT 描画」が
  シャドウマップを恒久的に壊すため、AA は SMAA パス、ペイントは Canvas 2D 方式を採用している。
- カメラの `near` を 0.1 まで下げると深度精度が落ち、GTAO が近距離で黒い矩形状のノイズを出す。
  現在は `near=0.3 / far=460`。`far` を変える場合は空の球（半径 360）と海（620 四方）が
  はみ出さないか確認すること。はみ出すと空がクリップされて黒く抜ける。
- 射撃は「そのフレームの姿勢」から発射点と方向を決めている（`Agent.shoot`）。
  リグから取った銃口ワールド座標は 1 フレーム古く、ダッシュ中に壁の内側から発射されて
  弾が即消滅する。カメラ更新をエージェント更新より前に置いているのも同じ理由。
- マウスの押下は `Input.firePressed` でラッチしている。`buttons[0]` を直接見ると
  1 フレームより短いクリックを取りこぼす。
- 触手のアニメーションでは根元の `baseX` / `baseY` を必ず足すこと。
  上書きすると触手の生える向きが壊れる。
